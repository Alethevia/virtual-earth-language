# 研究稿与复现材料

已将纽约和新英格兰的结果整理为一份[完整英文研究稿](MANUSCRIPT.md)，
含研究问题、相关文献、数据口径、方法、结果、限制、图表与复现说明。
这是一份工作稿，尚未投稿或经过独立科学评阅。

稿件的核心判断是：**加入站点标签的增量效果依赖年份、模型与基线，
现有证据不支持稳定提升高负荷日预测。** 两地都使用同日实测天气，
因此不宣称实际日前预测或交易用途。

本轮没有新增调参实验。它完成了三项工作：

- 对照5篇直接相关研究核查定位，尤其是2025年的空间气象图模型论文。
  多站点与地理气象预测已有研究，不能作为我们的原创点。
- 自动从已发布结果生成8行跨地区比较表与区间图，保留原始、辅助及事后
  分析的区别，没有合并成一个“总体成功率”。
- 从已提交的数据和代码重新执行新英格兰全部65次拟合：694天、13个流程、
  9,022个模型预测逐值一致，预测CSV逐字节一致；没有使用本地原始数据缓存。
