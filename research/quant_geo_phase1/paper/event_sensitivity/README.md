# 连续高负荷日的影响诊断

执行日期：2026-11-04。**事后描述性分析，不是新的确认性实验。**
本分析只读取已发布预测，新增模型拟合次数为0。没有删除原始实验的任何日期。

## 方法与边界

按原训练期门槛筛选已观测高负荷日：NYISO为24,966.5 MW，ISO-NE为
19,045.328 MW。将日历上连续的高负荷日组成一个“观测连续段”。普通日和
缺失日均使连续段断开。这些段不是经天气资料识别的热浪，也不假设相互独立。
特别是ISO-NE 2025遗漏的4个高负荷日可能割裂真实事件，因此这里的11段
只描述完整案例，不代表全年真实事件数。

每次在计算指标时排除一段，保留原模型和其余日期，重新计算
`mean(|actual-B2| - |actual-B3|)`。正值支持B3。报告所有逐段排除结果，
不选择性排除不利事件。排除后的范围是确定性的敏感性范围，**不是置信区间**。
不同长度的段会移除不同数量的日期，因此影响不能解释为某种事件的因果效应。
`summary.csv`另列各段均值等权平均；它改变估计目标，只供描述，不替代按日加权的原端点。

- **NYISO 2024 HGB：**排除6月18—23日的6天，剩余平均收益由原来的
  +27.90变为−30.96 MW。原正向点估计对这段日期敏感。
- **ISO-NE 2024 HGB：**排除7月5—18日的14天，剩余平均收益由
  +30.24变为−72.26 MW。该段占已观测高负荷日的一半，不能视为小扰动。
- **NYISO 2025 HGB：**逐段排除后的收益均为正，但最低只剩+3.95 MW。
  这不解决原主区间跨零的问题，也不证明能承受同时移除多段。
- **ISO-NE 2025 HGB：**逐段排除后均为负（−77.47至−44.67 MW）。
  观察到的负向结果并非仅靠某一个连续段才成立；缺失事件和样本不足仍未解决。
- 两地Ridge的年度方向在逐段排除后均保持不变。模型之间的差异仍然存在。

本诊断进一步支持“结果依赖年份、模型及事件构成”的有限判断。它没有
提供新的预测方法或独立验证数据，不能提高原实验的筛选等级。

## 核验与运行

三个输入CSV均与源提交的Git blob哈希匹配，SHA-256保存在`inputs.json`。
8个原始均值及样本数与论文已发布表一致；对全部66项逐段排除结果，另用
直接筛除日期、分别计算B2和B3 MAE的方式核验，最大差异约9.95×10⁻¹⁴ MW。
见`verification.json`。这是同一研究流程内的算术核验，不是第三方评阅。
4项单元测试覆盖缺失/普通日断段、按日加权、重复/无效输入和不可排除的单段。

在`research/quant_geo_phase1`运行，仅需Python标准库：

```bash
python paper/event_sensitivity/analyse.py
python paper/event_sensitivity/analyse.py --check
python -m unittest discover -s paper/event_sensitivity -p 'test_*.py' -v
```

输入固定于提交`d77f7c57535bb8864db5abb9e6649f06c370abde`。
`events.csv`保留每段的日期、天数、贡献和排除后的结果；`summary.csv`保留8项汇总。
